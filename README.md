# Second-dose models

Interactive models that accompany a modeling paper on a second modified live vaccine dose in
adult shelter cats and dogs. Served at https://rekreisler.github.io/adult-second-dose/.

- `cats.html`: second panleukopenia dose in adult cats
- `dogs.html`: second distemper and parvovirus dose in adult dogs
- `timing.html`: timing of the second dose
- `examples/`: synthetic record files in the layout the models read

This repository is generated by a build script kept with the paper's analysis code. Do not edit
these files by hand. Each page runs entirely in the browser, and uploaded records never leave it.
